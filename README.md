# Surface of Abyss

A compact 2D GameMaker project maintained as a professional continuation of the original Surface of Abyss release.

## Overview

Surface of Abyss is a small playable 2D game built in GameMaker. It includes platforming, room transitions, simple combat encounters, a shop interface, and video cutscenes.

This repository preserves the original project structure inside GameMaker while improving repository organization, documentation, and maintainability around it.

## Repository Layout

```text
game/     GameMaker project files
assets/   Repository presentation assets such as screenshots
docs/     Maintenance notes and supporting documentation
builds/   Optional exported builds or release notes
```

The GameMaker project is located at:

```text
game/Surface of Abbyss/Surface of Abbyss.yyp
```

The internal project folder keeps the original spelling to avoid unnecessary project churn.

## How to Run

1. Install GameMaker.
2. Open `game/Surface of Abbyss/Surface of Abbyss.yyp`.
3. Select the desired target platform in GameMaker.
4. Run the project from the IDE.
